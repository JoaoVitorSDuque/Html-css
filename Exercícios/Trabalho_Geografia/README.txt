PISA — site escolar mobile

Arquivos:
- index.html
- style.css
- script.js
- assets/

Para usar:
1. Extraia a pasta.
2. Abra index.html no celular/navegador.
3. Para publicar, a pasta inteira pode ser enviada para GitHub Pages, Netlify, Vercel ou outro host estático.

O efeito de imagem fixa usa background-attachment: fixed nas seções de destaque; há um fallback para dispositivos Apple que limitam esse comportamento.
